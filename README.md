## HORCRUX homelab

HORCRUX is my hands-on infrastructure lab and long-term engineering project. The current environment includes:

- Proxmox VE virtualization on repurposed enterprise hardware
- Linux and Windows virtual machines
- Grafana monitoring and a dedicated physical command-center kiosk
- Intel integrated-GPU passthrough and a portrait status display
- Secure remote administration
- Recovery runbooks, restore planning, and system documentation
- Custom health-check and operational tooling

Public documentation is intentionally sanitized to protect internal addresses, credentials, and infrastructure details.

## Engineering approach

```text
Observe → Isolate → Test → Automate → Document → Verify
```

I favor evidence-driven troubleshooting, incremental changes, read-only diagnostics, reproducible testing, and documentation that another technician can actually follow.
